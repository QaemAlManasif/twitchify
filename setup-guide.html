Twitchify Setup Guide
XENEON EDGE ready

Twitch on your XENEON EDGE, in about two minutes

Import one file, place the widget, and approve a code on twitch.tv. There is no developer console to visit, no Client ID to paste, and nothing to configure before it works.

iCUE 5.45 or newer
Windows
No developer keys
No background app required

Before you start

Four things, and you almost certainly have all of them already.

✓

A CORSAIR XENEON EDGE

The touchscreen the widget runs on.

✓

iCUE 5.45 or newer

Older builds cannot load the widget. Update from iCUE's own settings.

✓

A Twitch account

Any account. You do not need to be a streamer or a moderator to read chat.

✓

Windows

iCUE's widget support for the EDGE is Windows only.

Setup

Three steps. Only the last one needs your attention.

1
Download and import the widget

Grab twitchify.icuewidget from the releases page.

  1. Download twitchify.icuewidget.
  2. Double-click it. iCUE picks it up and imports it.
  3. If nothing happens, open iCUE, go to the Widgets panel and use the + button, then choose the file.
Download from Releases
2
Place it on your EDGE

Open your EDGE's layout in iCUE and drag Twitchify onto it.

  1. Pick a size. M or L suits chat well; XL gives room for the dashboard column beside it.
  2. The widget's own settings appear beside the layout, with Widget type at the top.
  3. Leave the type on Chosen in the widget for now. You can change it any time.
Tip You can place Twitchify more than once and give each copy a different job. See One widget, any job below.
3
Connect your Twitch account

On the EDGE, tap Connect Twitch. A short code appears.

  1. Your browser opens twitch.tv/activate automatically. If it doesn't, tap Copy link and open it on your phone or PC.
  2. Sign in to Twitch if you aren't already, and enter the code shown on the EDGE.
  3. Approve the permissions. The widget picks it up on its own within a few seconds.
That's it Your own channel, every channel you moderate, and the channels you follow that are live all appear in the list. Nothing else to configure.
Why a code and not a password Twitchify never sees your Twitch password. Approval happens on Twitch's own site, and the token it hands back is stored only on your PC.

One widget, any job

Add Twitchify to the screen more than once and set Widget type on each copy in iCUE's settings.

Everything

Chat plus a dashboard column. Each section can sit in the panel, as a strip across the top, or folded into the chat.

Chat and controls

The chat on its own, with the moderation tools and the message box.

Activity feed

Follows, subs, gifts, cheers and raids as they happen, with filters.

Stats

Live status and uptime, viewers, followers, subscribers, chat pace, session totals.

Quick actions

Chat modes, Shield Mode, clip, marker, ad break and raid as large touch tiles.

Custom panel

Any embeddable link, the same kind you'd use as an OBS browser source. Paste it into Custom panel link.

Good to know Every copy shares the sign-in, so you only connect once. Switch channel in one and the others follow. Each copy keeps its own text size, set in iCUE's settings for that widget.

Watch Sync — optional

Shows the chat of whatever Twitch channel you have open in your browser, and can follow the tab you're watching. Skip this section if you don't want it — everything above works without it.

1
Install the helper

Download and run Twitchify-Watch-Sync-Setup.exe from the same releases page.

SmartScreen will warn you The helper isn't code-signed yet, so Windows shows a blue "Windows protected your PC" box. Choose More info, then Run anyway. If you'd rather not, the source is public and you can build it yourself.
What it does The helper is a small program with no window. It runs with iCUE — asleep until iCUE is open, doing nothing otherwise — and passes channel names from your browser to the widget. It is uninstalled from Settings → Apps like anything else.
2
Add the browser extension

The store listings aren't live yet, so load it manually for now. It takes a minute.

  1. Download twitchify-watch-sync-chrome-1.0.0.zip (or the Firefox one) and unzip it to a folder you'll keep.
  2. Chrome, Edge, Brave, Opera: open chrome://extensions, turn on Developer mode, click Load unpacked and pick that folder.
  3. Firefox: open about:debugging#/runtime/this-firefox, click Load Temporary Add-on and pick the manifest.json inside the folder.
Firefox note A temporary add-on is removed when Firefox restarts. Reload it, or wait for the store listing.
3
Turn it on in the widget
  1. On the EDGE, open Preferences (the sliders button in the header).
  2. Turn on Channels open in my browser.
  3. Optionally turn on Follow the focused tab so the chat switches with you.

The Connection section at the top of Preferences shows Twitch, Helper and Extension as three live indicators, so you can see exactly which piece isn't talking.

Privacy Only channel names travel, and only to 127.0.0.1 — your own PC. No page content, no cookies, no messages, and nothing to any server. Full privacy policy.

If something doesn't work

The code expired, or nothing happened after I approved it
Codes are valid for a limited time. Tap Cancel and then Connect Twitch again for a fresh one.
  • If the browser never opened, use Copy link and paste it somewhere yourself. Some hosts block a widget from opening links.
  • The code survives a reload, so if the widget restarted mid-sign-in it will still be waiting.
It says "sign out and connect again"
A feature is asking for a permission your sign-in predates. Twitch cannot add permissions to a token that already exists, so the fix is a fresh sign-in.
  • Open Preferences, scroll to the bottom, tap Sign out, then connect again.
  • Nothing is lost — your layouts, pins and preferences are kept.
I can't see the moderation buttons
Moderation tools only appear in channels where you actually hold the powers.
  • In a channel you merely watch, tapping a message shows a note instead of buttons. That is expected.
  • Stream info, clip, marker, ad break and raid are for your own channel only.
  • If you were made a moderator recently, sign out and connect again so the list refreshes.
Chat is empty, or says it can't read this chat
  • Check the Connection indicators in Preferences. If Twitch isn't green, it's a network or sign-in problem, not the channel.
  • A channel with genuinely no messages since you opened it will look empty — the widget shows live chat, not history.
  • If it mentions authorization, sign out and connect again.
Watch Sync says "helper offline"
The widget cannot reach the helper on 127.0.0.1:57123.
  • Make sure the installer has been run, and that iCUE is open — the helper sleeps when it isn't.
  • Preferences has a Start helper button beside the indicators. Tap it.
  • If a firewall is blocking loopback connections, allow TwitchWatchHelper.exe.
  • Still stuck? The log is at %LOCALAPPDATA%\TwitchModeration\helper.log.
The helper is running but the extension shows "not detected"
  • Open the extension's popup from the browser toolbar. It reports whether it can see the helper.
  • The badge shows a number when channels are being shared. No number means no Twitch tabs are open, or it isn't talking.
  • Reload the extension from chrome://extensions and open a Twitch tab.
A custom panel is blank
Most ordinary web pages refuse to be embedded in another page, and the Twitch dashboard is one of them. There is no way around it from outside.
  • Use links built for embedding — StreamElements or Streamlabs overlays, alert boxes, goal bars.
  • These are the same links you would paste into an OBS browser source.
The widget looks cramped, or text is too small
  • In iCUE's settings for the placed widget there's a Text size group — an overall slider plus one for chat, the channel list, buttons and the dashboard.
  • Each copy of the widget has its own, so a Stats tile can run large while chat stays dense.
  • In Preferences, Density and Button size change how much fits on screen.
